# Images

This directory contains all the images used in the application.

## Directory Structure

- `avatars/`: User avatars and profile pictures
- `cards/`: Images used in cards and content blocks
- `icons/`: Icon images (when not using SVG or icon fonts)
- `illustrations/`: Larger illustrations and graphics
- `apps/`: Application-specific images
  - `academy/`: Academy-related images
  - `ecommerce/`: E-commerce-related images
  - `kanban/`: Kanban-related images
  - `logistics/`: Logistics-related images
- `front-pages/`: Images used on front/landing pages

## Guidelines

1. Use appropriate image formats:
   - JPEG for photographs
   - PNG for images with transparency
   - SVG for icons and simple graphics
   - WebP for better compression when browser support is not an issue
2. Optimize images for web use
3. Use descriptive filenames
4. Group images by purpose or feature
