# Hooks

This directory contains custom React hooks used throughout the application.

## Purpose

Custom hooks allow us to extract component logic into reusable functions. They should:

1. Follow the React hooks naming convention (use prefix)
2. Be focused on a single concern
3. Be well-documented with usage examples
4. Be thoroughly tested

## Examples

- `useAuth`: Authentication-related hooks
- `useForm`: Form handling hooks
- `useApi`: API interaction hooks
