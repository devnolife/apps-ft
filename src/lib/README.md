# Library

This directory contains library code and third-party integrations.

## Directory Structure

- `apollo/`: Apollo Client setup and GraphQL-related utilities
- `auth/`: Authentication utilities and configurations
- `redux/`: Redux store, slices, and related utilities

## Guidelines

1. Keep third-party integrations isolated in their respective directories
2. Provide clear interfaces for the rest of the application to use
3. Document configuration options and usage patterns
4. Minimize direct dependencies on third-party libraries outside these directories
