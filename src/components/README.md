# Components

This directory contains all reusable UI components used throughout the application.

## Directory Structure

- `common/`: Common components used across the app (buttons, cards, etc.)
- `forms/`: Form-related components (inputs, selectors, etc.)
- `layout/`: Layout components (headers, footers, sidebars, etc.)
  - `dashboard/`: Dashboard-specific layout components
  - `navigation/`: Navigation components (menus, breadcrumbs, etc.)
- `ui/`: Basic UI components (typography, icons, etc.)

## Guidelines

1. Components should be reusable and not contain business logic
2. Each component should have a clear, single responsibility
3. Components should be well-documented with props and usage examples
4. Use consistent naming conventions (PascalCase for component files)
