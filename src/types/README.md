# Types

This directory contains TypeScript type definitions used throughout the application.

## Purpose

Type definitions help ensure type safety and provide better documentation and IDE support. This directory contains:

1. Interface definitions for data models
2. Type definitions for API responses and requests
3. Shared type definitions used across multiple components
4. Utility types

## Guidelines

1. Group related types in separate files
2. Document complex types with comments
3. Use consistent naming conventions
4. Keep types in sync with the actual data structures
