# Utilities

This directory contains utility functions used throughout the application.

## Purpose

Utility functions are pure functions that:

1. Perform a specific task
2. Do not have side effects
3. Are reusable across the application
4. Are not tied to React or UI components

## Guidelines

1. Group related utilities in separate files
2. Document each utility function with JSDoc comments
3. Write tests for utility functions
4. Keep utilities simple and focused on a single concern
