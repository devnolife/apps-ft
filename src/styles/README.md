# Styles

This directory contains global styles and theme configurations.

## Purpose

The styles directory is responsible for:

1. Global CSS styles
2. Theme configurations (colors, typography, spacing, etc.)
3. Style utilities and mixins
4. CSS reset and normalization

## Guidelines

1. Component-specific styles should be co-located with their components
2. Global styles should be minimal and focused on app-wide concerns
3. Use consistent naming conventions for CSS classes and variables
4. Document theme configuration and usage patterns
